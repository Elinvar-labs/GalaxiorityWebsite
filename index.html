📖 About the Project

🚀 *Keep distance, maneuver, and fire rockets against the most dangerous targets.*

Project Galaxiority — a third-person space action game. The player controls a fighter jet, deflects attacks from waves of enemy ships across four classes, dodges asteroids, and battles bosses that appear every fifth wave.

✨ Features

  • 🛸 Four Enemy Classes — Light, Medium, Heavy, and Boss. Each class has its own model (Striker, Insurgent, Dispatcher, Zenith), with unique speed, durability, and weaponry characteristics
  • 🌊 Wave System with gradually increasing difficulty. Every fifth wave is a boss wave with escort ships
  • 🎯 Two Types of Weapons for the Player: Twin lasers on the wings and a heavy self-guiding rocket in the engine nozzle
  • 💥 Enemy Behavior: Closing distance to the player and maintaining preferred distance, side maneuvering with periodic direction changes, and firing only upon hitting the aiming cone
  • 🪨 Destructible Asteroids with individual durability reserves and respawning in the area around the player
  • ❤️ Status Indication: Health bars above enemies and a separate health bar for the boss at the top of the screen
  • 🧭 Enemy Indicators: On-screen indicators for enemies out of sight
  • 🌌 Procedural Skybox, starfield, and particle system for explosions
  • 🎮 Gamepad and Keyboard Support

📦 Installation


# Clone the repository
git clone https://github.com/Elinvar-labs/Project_Galaxiority

# Navigate to the directory
cd Project_Galaxiority

# Install dependencies
uv sync

# Run the game
uv run project-galaxiority

HeavyDispatcher.gltf240Triple spread, ~1.0 per secondLow speed, high damage
BossZenith.gltf1800Wide spread of five cannonsSeparate health bar

All classes include the following behavior: closing distance to the player and maintaining a preferred distance; side maneuvering with periodic direction changes; firing only upon hitting the aiming cone; returning to combat zone upon excessive distance from the player.

🌊 Waves

  • Every fifth wave is a boss wave: one or more bosses accompanied by medium ships.
  • In regular waves, the composition gradually expands: light, then medium, then heavy.
  • A pause of about three seconds with a countdown in the top of the screen is provided between waves.

⚖️ Balance

Key numerical parameters are located in enemy_types.py and at the top of main.py. Settings like ENEMY_SPAWN_DISTANCE, ENEMY_INTER_WAVE_DELAY, and the _wave_plan() function allow changing difficulty without modifying the AI logic.
